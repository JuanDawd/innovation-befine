## C. Mobile shell (stylists & clothiers — primary devices)

- `components/app-shell.tsx:318` floating name/bell pill is `fixed` with no reserved space → overlaps page H1 (seen on "Mis ganancias").
- `components/app-shell.tsx:327-330` bottom nav `h-16` + `pb-16` with no `env(safe-area-inset-bottom)` → iPhone home indicator overlaps the tabs; no `viewport-fit=cover`.

- Clothier/stylist primary buttons OK size (≥44 px); "Ver notas" toggles are small text links.

## D. Guideline violations (file:line)

### Accessibility / focus

- `components/ui/sidebar.tsx:255` — trigger's sr-only text is English "Toggle Sidebar"
- `app/(protected)/admin/analytics/analytics-dashboard.tsx:171` — `<tr onClick>` expandable row; needs a `<button>` (keyboard) + `aria-expanded`
- `components/request-edit-dialog.tsx:135` — `focus:outline-none` → use `focus-visible:` ring
- `app/(protected)/large-orders/line-accordion.tsx:122,140,164,177,192,206,218,230,243` — controls without `id`/`htmlFor` or `aria-label` (quantity/price spinbuttons unnamed in walkthrough)
- `app/(protected)/large-orders/create-large-order-form.tsx:172,240,263,277,290,305,318` — same
- `app/(protected)/large-orders/[id]/large-order-detail.tsx:392,403,616` — same
- Absences calendar prev/next month buttons, catalog price/commission (placeholder-only), walk-in icon button — see L-51
- No skip-to-content link in `app-shell.tsx`

### Animation

- No `prefers-reduced-motion` handling anywhere (`motion-safe:`/`motion-reduce:` unused)
- `transition-all` → list properties: `components/ui/progress.tsx:29`, `components/cashier-dashboard.tsx:163`, `components/app-shell.tsx:215`, `components/service-catalog.tsx:848,921,947`, `app/(protected)/admin/analytics/analytics-dashboard.tsx:337`, `app/(protected)/large-orders/[id]/large-order-detail.tsx:890`, `app/page.tsx:189,204`, `app/login/page.tsx:202`, `app/roadmap/page.tsx:56`, `app/(protected)/admin/roadmap/page.tsx:234`

### Typography / copy / i18n

- `app/(protected)/admin/analytics/analytics-dashboard.tsx:191` — hard-coded "Cargando..." → i18n + "…"
- Hard-coded Spanish bypassing next-intl: `analytics-dashboard.tsx:227`, `large-orders/[id]/large-order-detail.tsx:779`, `components/create-product-form.tsx:194`, `components/checkout-form.tsx:242`, `app/(protected)/admin/settings/page.tsx:22`, `app/(protected)/cashier/checkout/page.tsx:27`, `app/global-error.tsx:21`
- Money columns: ensure `tabular-nums` (most use `font-mono`, OK; payroll lines and large-order totals mixed)

### Locale / hydration

- Times rendered without `timeZone: "America/Bogota"` (UTC on server, hydration mismatch): `components/business-day-panel.tsx:122,132`, `components/closed-ticket-history.tsx` — M-63
- Dates via `toLocaleDateString` without timeZone: `large-orders/[id]/large-order-detail.tsx:518,759`, `large-orders/large-orders-table.tsx:102`, `admin/payroll/payroll-screen.tsx:444`, `admin/absences/absence-calendar.tsx:101,185,238`
- → route all through one `Intl.DateTimeFormat` helper with the business timezone

### Theming

- `app/layout.tsx:41` — `themeColor: "#E9408E"` (pink) doesn't match the near-black background; use per-scheme `themeColor` (light/dark)
- No `color-scheme` set on `<html>` (dark scrollbars/inputs) — add `color-scheme: dark` under `.dark` / `light` otherwise
- Native `<select>` lacks explicit `bg-background text-foreground` in several forms (A4)

### Performance

- `admin/payroll/payroll-screen.tsx` renders one button per unsettled day (166) — replace with range picker (B7)
- Client list / ticket history `.map()` without pagination or virtualization once data grows (>50 rows)

## Suggested order

1. **Feedback correctness** (B1, B3, B5) — fixes the "did it save?" confusion; small code changes, biggest trust gain.
2. **One design system** (A1–A8) — define tokens & a single `PageHeader`, `StatusBadge`, `Select`, `formatCOP`/`formatTime`; replace raw colors/selects. Use the `ui-ux-pro-max` skill to pick the palette/typography/spacing scale once, then apply screen by screen.
3. **Mobile shell** (C) — safe areas, header spacing, touch-action. Stylist & clothier first.
4. **Speed** (B2) — move dialog data loading off server actions.
5. **A11y & i18n sweep** (D) — mechanical, can be done in one pass with lint rules (`jsx-a11y`, i18n no-literal-string).
