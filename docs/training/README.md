# Guías de uso — BeFine

Guías de capacitación interna, una por rol, con capturas de pantalla reales de la app. Empieza siempre por **Primeros pasos**.

| Rol             | Archivo                        | Tareas principales                                                               |
| --------------- | ------------------------------ | -------------------------------------------------------------------------------- |
| Todo el equipo  | [common.md](common.md)         | Iniciar sesión, menú de usuario, cambiar contraseña, notificaciones               |
| Cajera          | [cashier.md](cashier.md)       | Abrir/cerrar día, cobrar, ajustar precios, vender prendas, aprobar cambios        |
| Administradora  | [admin.md](admin.md)           | Analítica, empleados, aprobar piezas, nómina, catálogo, ausencias, configuración  |
| Secretaria      | [secretary.md](secretary.md)   | Agendar citas, clientes, productos para el taller, pedidos grandes                |
| Estilista       | [stylist.md](stylist.md)       | Registrar servicios, marcar listo para cobrar, solicitar cambios, ver ganancias   |
| Confeccionista  | [clothier.md](clothier.md)     | Reclamar piezas, marcar como listas, ver ganancias                                |
